# NOVA - Futuristic AI Virtual Assistant 🔮

NOVA is a voice-activated, high-tech AI virtual assistant web application featuring an interactive 3D holographic canvas particle orb, real-time speech-to-text, natural voice synthesis, procedural sci-fi audio effects, and hybrid intelligence (instant local tools + Google Gemini AI brain).

![NOVA Assistant Interface](https://raw.githubusercontent.com/placeholder/preview.png)

## ✨ Features

- 🔮 **Holographic Audio Orb**: Dynamic multi-layer canvas particle visualizer reacting to `IDLE`, `LISTENING`, `PROCESSING`, and `SPEAKING` states with mouse parallax.
- 🎙️ **Voice & Audio Pipeline**: Real-time microphone speech recognition, natural text-to-speech synthesis, and custom procedural sci-fi sound effects using Web Audio API oscillators.
- 🧠 **Universal AI Intelligence**: Powered by Google Gemini (`gemini-3.8-flash` and `gemini-3.1-flash-lite`) with multi-model auto-failover to ensure uninterrupted answers for any query.
- ⚡ **Instant Local Tools**:
  - 🕒 Real-time system clock and calendar date
  - 🌦️ Live global weather via Open-Meteo API
  - ⏱️ Countdown timers with visual cards and sound alarms
  - 🧮 Instant mathematical calculations and percentage evaluations
  - 🔍 Web launchers (YouTube search & play, Google, Wikipedia, GitHub)
  - 📝 Scratchpad notes stored in LocalStorage
  - 🎲 Tech jokes, inspirational quotes, coin toss, and dice rolls
- 💎 **Sci-Fi Glassmorphism UI**: High-tech HUD design, real-time transcript feed, quick command chips, and slide-out Settings & Tools drawers.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)

### Installation
```bash
# Clone the repository
git clone https://github.com/Samiksha-Patil-1/nova-virtual-assistant.git

# Navigate into directory
cd nova-virtual-assistant

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

## ⚙️ Configuration

Open the **Settings (⚙️)** drawer in the app to configure:
- Google Gemini API Key
- AI Model selection
- Voice selection & speech rate/pitch
- Sound effects toggle
